# Software Architect | Senior Software Engineer | MSc @ Poli-USP

## 🧠 About Me
Computer Engineer focused on designing scalable, maintainable and well-architected systems.

I work with backend platforms, cloud-native infrastructure and distributed systems, applying principles such as Clean Architecture, Domain-Driven Design and event-driven architectures.

Currently I coordinate undergraduate technology programs at the **Mauá Institute of Technology** while pursuing my **Master's degree in Computer Engineering at the University of São Paulo (Poli-USP)**.

My work involves building production systems, designing software architectures and leading technical decisions across cloud platforms and modern development stacks.
